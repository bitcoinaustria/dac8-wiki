# DAC8 Austrian and European Implementation Wiki

Open-source evidence base on DAC8, the Austrian Krypto-MPfG, related EU law, and possible constitutional and EU judicial-review routes.

## Current scope

The current work supports the Austrian legal and research effort. It concentrates on:

- Austrian implementation and possible national additions;
- proceedings involving affected individuals and regulated providers;
- DSB, BVwG, VfGH, VwGH, and CJEU routes;
- fundamental rights, data protection, MiCA, TFR, and AML interactions;
- favorable and adverse precedent, procedural barriers, and missing evidence.

## Future direction

The repository is intended to become reusable for comparable proceedings in other European countries. That is a later extension, not a reason to generalize Austrian findings today. Each country will require its own implementation texts, remedies, standing rules, evidence, and counsel review.
